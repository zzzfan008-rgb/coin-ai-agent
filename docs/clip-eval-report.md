- **模型**: `openai/clip-vit-base-patch32` (ViT-B/32, 512-dim embedding)
- **评测库**: `transformers==5.17.0`, `torch==2.14.0`
- **运行设备**: CPU (GPU 到位后直接切换)

### 数据集
| 字段 | 值 |
|------|-----|
| 样本数 | 82 |
| 图片路径 | `data/images/` |
| 标注文件 | `data/annotations.json` |

### 评测任务
对于每条记录 `(image, text, hard_negative)`:
1. 用 CLIP 提取图像 embedding (pooled output, 512-dim, L2-normalized)
2. 分别提取 `text` 和 `hard_negative` 的文本 embedding
3. 计算 `image` 与两个文本的余弦相似度
4. **正确** 当且仅当 `text_score > hard_negative_score`

### 指标定义
- **Top-1 准确率**: 正确次数 / 总次数
- **分项准确率**: 按 category / style / color 分别统计

## 样例分析

### 易错样本特征

以下为 49 条错误案例中最典型的几类：

**1. 白色/米白衣物混淆率高 (白底图干扰)**
```
[T恤/休闲温柔] text=0.180  hn=0.235  diff=-0.055
  TEXT:  米白棉质V领宽松T恤
  HN:    黑色修身V领针织衫

[T恤/休闲] text=0.210  hn=0.238  diff=-0.028
  TEXT:  薄荷绿棉质印花宽松T恤
  HN:    白色修身衬衫
```
> **分析**: 白底商品图与白色衣物文本高度相似；背景消融不足导致 CLIP 难以区分主体与背景。

**2. 宽松版型 vs 修身版型区分困难**
```
[T恤/休闲通勤] text=0.179  hn=0.213  diff=-0.034
  TEXT:  米白棉质圆领修身T恤
  HN:    灰色宽松polo衫
```
> **分析**: "宽松" vs "修身"这类细粒度属性词在 ViT-B/32 的 77 token 限制下与图像细节难以对齐。

**3. 针织上衣 vs T恤 品类交叉**
```
[针织上衣/休闲] text=0.199  hn=0.227  diff=-0.028
  TEXT:  白色棉质V领针织开衫
  HN:    米白色宽松圆领T恤
```
> **分析**: 针织面料的视觉特征（纹理）与 T 恤相似，版型描述词不精确时 CLIP 无法区分。

### 正确案例特征

准确率高的针织上衣、polo衫等品类往往有：
- **强视觉特征**: 针织纹理（knit texture）、领口细节（polo 领）、口袋
- **颜色饱和度高**: 黑色/灰色/浅蓝准确率 >66%，与背景差异大
- **hard_negative 风格差异明显**: 针织 vs T 恤，hard_negative 为不同品类时更易区分

### 决策边界分析

| 指标 | 正确案例 | 错误案例 |
|------|---------|---------|
| 平均 text_score | 0.235 | 0.218 |
| 平均 score diff | +0.014 | -0.014 |
| \|diff\| < 0.05 的比例 | — | **97.96% (48/49)** |

> **关键发现**: 错误案例中 98% 属于"边缘误判"（|diff| < 0.05），说明 CLIP 整体不确定度高，并非逻辑性错误，而是置信度接近。当前模型在边界附近的随机波动导致约 40% 准确率。

## 结论

### 当前 CLIP 覆盖度评估

| 维度 | 评估 |
|------|------|
| **总体准确率** | **40.24%** — 不足以直接替代 DashScope，需改进 |
| 品类覆盖 | 针织上衣(83%) / polo(100%) 优于 T恤(31%) |
| 颜色覆盖 | 深色系(黑/灰/蓝) >67%，浅色/白色 <25% |
| 细粒度属性 | 宽松/修身/版型等属性词区分能力弱 |
| 决策稳定性 | 97% 错误为边缘案例，模型处于决策边界 |

### 改进方向

1. **升级 CLIP 模型**: ViT-L/14 或 SigLIP 预期能显著提升细粒度分类能力
2. **数据增强/白底图处理**: 对白色/米白背景图做 mask 或 text prompt 注入
3. **中文微调**: 在时尚领域中文数据集上做 LoRA 微调，提升颜色/版型词理解
4. **hard_negative 策略优化**: 当前 hard_negative 多为相似品类+相反颜色组合，真实场景中更难的 negative 可能表现更差
